# Consumo Consciente — Semeando Futuro

Landing page institucional independente do aplicativo Consumo Consciente.

## Desenvolvimento

Este projeto é uma página estática, sem etapa de build ou dependências de JavaScript. O arquivo de entrada é `index.html`.

## Publicação

### Vercel
1. Importe `wzrichardy/consumo-consciente` na Vercel.
2. Selecione **Other** como framework preset, se solicitado.
3. Deixe Build Command e Output Directory vazios (ou sem build).
4. Faça o deploy.

### GitHub Pages
1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.

## Destino do aplicativo

Os links de acesso direcionam para https://consumo-consciente.base44.app. A landing page não modifica nem substitui o aplicativo Base44.
